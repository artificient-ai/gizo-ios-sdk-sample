🚗 Trip Recording Modes

Our SDK supports two modes of trip data recording:
Automated Trip Recording
The SDK automatically detects and records trips in the background based on motion and activity recognition. Ideal for fully passive use cases where user interaction should be minimized.
Manual Trip Recording
Developers can programmatically start and stop trip recording based on specific app logic or user actions.

💡 Choosing a Mode:Before integrating, consider your app’s use case:
Use automated mode if you want seamless, always-on data collection without user involvement. Useful for:
Continuous fleet tracking
Insurance telematics
Mobility tracking
Use manual mode if trip recording needs to be controlled explicitly. Useful for:
Gig workers starting a job (e.g., food delivery or ride-hailing)
Users unlocking a shared vehicle or rental car
Triggering trip recording from a specific app screen or button
